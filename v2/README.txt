Система для аренды квартир (учебная практика ПМ 03)

Версия 2 (папка v2): версия 1 + роли пользователей, новый стиль, вычислительный эксперимент (скидка за срок аренды).

Запуск:
1. Открыть ArendaKvartir.csproj в Visual Studio 2019/2022 (нагрузка "Разработка классических приложений .NET", .NET Framework 4.8).
2. Нажать F5. При первом запуске файл базы Аренда.accdb создаётся автоматически в папке с exe.
   (Если рядом лежит база версии 1, она будет дополнена автоматически: роли, скидка, пароли в виде хэша.)
3. Требуется Microsoft Access Database Engine (Microsoft.ACE.OLEDB.12.0), разрядность как у сборки (x64 по умолчанию).

Учётные записи (логин / пароль):
  admin    / admin     - Администратор
  manager  / manager   - Менеджер
  buyer    / buyer     - Покупатель (привязан к клиенту "Иванов Иван Иванович")
  user     / user      - Пользователь

Роли:
  Администратор - всё, что у менеджера + управление пользователями (Form7)
  Менеджер      - квартиры (добавление/изменение/удаление), клиенты, договоры всех клиентов, расчёт
  Покупатель    - каталог квартир (по умолчанию только свободные), свои договоры и оформление аренды, расчёт
  Пользователь  - только просмотр каталога квартир и расчёт стоимости
Покупатель и Пользователь могут зарегистрироваться сами на форме входа (Form6).

Формы:
  Form1 - вход                          Form5 - договоры аренды (скидка за срок)
  Form2 - главное меню (по ролям)       Form6 - регистрация
  Form3 - квартиры (поиск, фильтры)     Form7 - пользователи (админ)
  Form4 - клиенты (поиск)               Form8 - расчёт стоимости: таблица и диаграмма по срокам

Скидка за срок аренды: от 6 мес. - 5%, от 12 мес. - 10%, от 24 мес. - 15%
(правила в Calc.cs, метод DiscountPercent).

Стиль задан в одном месте - Theme.cs (цвета, шрифты, кнопки, таблицы); каждая форма вызывает Theme.Apply.
