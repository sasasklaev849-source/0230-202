Система для аренды квартир (учебная практика ПМ 03)

Версия 1 (папка v1) - формы, база данных Access, авторизация.
Версия 2 (папка v2) - версия 1 + вычислительный эксперимент (расчёт стоимости аренды со скидкой за срок).

Запуск:
1. Открыть ArendaKvartir.csproj в Visual Studio 2019/2022 (нужна нагрузка "Разработка классических приложений .NET", .NET Framework 4.8).
2. Нажать F5. При первом запуске файл базы Аренда.accdb создаётся автоматически в папке с exe.
3. Вход: логин admin, пароль admin.

Требуется Microsoft Access Database Engine (драйвер Microsoft.ACE.OLEDB.12.0), разрядность как у Visual Studio-сборки (x64 по умолчанию).
